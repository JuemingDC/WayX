# WayX Converter Status

Updated: 2026-09-29

## Current production state

- Generic Loon Plugin → Quantumult X / Surge conversion is active.
- Source catalog uses original-source-only fetching.
- Source JavaScript is preserved unchanged; no wrapper/fork/prepend pipeline is allowed.
- Managed canonical QX/Surge outputs are regenerated by CI from the production converter.
- Converter Check covers syntax, checkpoint regressions, repository scripts, canonical regeneration, helper references, source URL preservation and golden outputs.

## Quantumult X

- QX snippet section labels remain comments.
- Rule mapping is behavior-based.
- Loon Plugin `PROXY` policy binding is preserved as literal `PROXY`; it is not lowered to built-in `proxy`.
- Loon `[Argument]` is **not converted** to QX parameter configuration or BoxJs.
- QX outputs do not copy source `[Argument]` declarations or Argument usage lists.
- If a Rewrite/Script declaration depends on Loon plugin arguments and cannot be represented with the same semantics, it is kept non-executable with a Review/Unsupported reason.
- Independent BoxJs content under `boxjs/` remains supported and is outside the Loon converter pipeline.

## Surge

- Generated output uses sgmodule sections and validated metadata.
- External/user policy bindings remain explicit Review/binding cases.
- Loon typed/dynamic plugin parameters are not fabricated into target configuration when no verified equivalent exists.

## Converter architecture

- Rule: `converter/src/rule.mjs`
- Rewrite v2: `converter/src/rewrite-v2*.mjs`
- Target regex: `converter/src/target-regex.mjs`
- QX semantic helpers: `converter/src/qx-semantic-script.mjs`
- Script v2: `converter/src/script-v2.mjs`
- Script target planner: `converter/src/script-v2-target.mjs`
- Loon Argument parser: `converter/src/argument.mjs`
- Loon Argument dependency analysis: `converter/src/argument-usage.mjs`
- Source compatibility: `converter/src/script-compat.mjs`
- Source/dependency fetch: `converter/src/source-fetch.mjs`
- Orchestration: `.github/scripts/sync-convert.mjs`

## Removed / obsolete directions

The following are no longer part of the converter design:

- Loon `[Argument]` → QX BoxJs generation;
- Loon `[Argument]` → QX `$prefs` bridge;
- rebuilding typed Loon `$argument` with wrapper scripts;
- freezing dynamic Loon plugin parameters to their defaults;
- plugin-specific adapter/whitelist conversion;
- source-script mirrors/fallbacks;
- historical phase notes that conflict with current production behavior.

Historical implementation details should be recovered from Git history instead of being kept as active specification.
