# 插件和源脚本备份

Modified: 2026-11-05 (chance). 每次 Actions 同步归档插件正文及其直接引用的脚本；Adblock 和 Module 使用目标客户端脚本，发布时与应用配置同目录。

| 内容               | 路径                                    | 用途                                           |
| ------------------ | --------------------------------------- | ---------------------------------------------- |
| 插件原始响应       | Resource/Backup/plugin/URL摘要/文件名   | 原始字节，含原作者署名、注释和来源绑定         |
| 脚本原始响应       | Resource/Backup/script/URL摘要/文件名   | 原始字节证据，不直接作为清理后的发布文件       |
| 共用兼容脚本       | 类型/客户端/来源作者/应用/脚本名.js     | 目标 API 适配及必要运行时，按需包含依赖        |
| API 引用清单       | Resource/Backup/script-api/URL摘要.json | 原件绑定、描述性 API 清单与运行时契约          |
| 出处及校验索引     | Resource/Backup/index.json              | 原地址、实际获取地址、SHA-256、大小、版本路径  |
| 本次覆盖及缺失清单 | Resource/Backup/status.json             | 已备份数量、改写产物数、404/网络失败及保留版本 |

获取仍请求作者原地址，通过统一 Surge UA、有限重试和共享字节快照完成。插件正文无变化也重新获取脚本。归档不修改 BOM、换行、脚本内部 API 或任何原注释；备份不能证明脚本跨客户端的 API 兼容性。

转换产物只替换活动脚本声明中的资源地址，原来源注释、正则、图标、跳转目标和参数保留。URL 查询参数区分资源；fragment 参数原样附到备份地址。内容变化时原位更新同一个备份文件，产物地址保持固定；SHA-256 和大小一并更新，旧字节通过 Git 历史保留。所有归档、索引和产物由现有 Actions 校验并在同一次 Git 提交发布。

Modified: 2026-11-08 (chance). 可莉目录发现及插件正文拉取已按用户指令重新暂停；保留已登记源快照，备份流程不补拉未登记的可莉插件正文。统一获取快照用于转换及原始字节归档；已确认失效的依赖仍只停用对应声明，已登记失效的整文件不请求。临时失败保留经过校验的历史版本，损坏归档、缺失 WayX 文件或事务错误阻止发布。

本地回归：`node tests/backups.ts`。本地只测试隔离夹具，不抓取或提交生产归档；实际源字节由 Actions 拉取。

Modified: 2026-11-05 (chance). Loon→QX、Loon→Surge、QX→Surge 使用独立目标程序，任务和 Module 工具同样参与 API 适配。发布目录及下次同步的还原流程见 [target-publication.md](target-publication.md)。脚本仅包含生效代码与必要许可，安装声明和原注释仍在原始归档。Resource/Backup/script-api-status.json 记录适配结果、原因和方案。缺少来源或声明不阻断转换；真实语法错误且无有效旧版本时仅停用对应声明。

Modified: 2026-11-05 (chance). 原生 Quantumult X 配置在格式有效时保留原文，JS 从原始归档逐字节复制（包括注释、BOM、换行），不包裹 API 运行时，不清理安装注释，不因 API 转换诊断停用原生声明。配置仅修正实际不规范的语法；目录迁移只重绑定配置中的脚本地址，不改原生 JS 正文。API 转换仅用于 Loon→QX、Loon→Surge、QX→Surge。此原生直拷政策优先于转换脚本的注释清理要求。
