## 目的和范围

对 Loon→QX、Loon→Surge、QX→Surge 提供通用 HTTP 去广告 API 兼容层。作者正文、函数、动态对象、键值、Env 接收者保持普通 JavaScript；不根据仓库某个脚本能否通过数据流证明来决定 API 是否可以转换。配置控制、任务、Module 工具和 Egern 不增加适配。

## 复用策略

固定 ScriptHub b943361f11be5795b3eb10f9cc4e5497642922fc 的 script-converter.js。复用其运行时 facade、Header 小写 Proxy、Promise/callback 桥接方式，不再添加另一套按具体源码写法放行的实现。Header 补 delete/has/descriptor/Symbol/原型方法处理；HTTP 补七方法、并发、拒绝与缺失响应、状态、字节和来源默认值；删除用原生删除方法或 null，不试写空字符串。禁止定时器空函数、全文替换 $done 和捕错后假放行。

## 作用域与执行

作者正文作为原样普通函数置于独立 API scope 内，语言本身处理类、this、参数、别名、Promise 和闭包。API scope 同时供直接全局名及 globalThis/window/global 访问，局部声明自然遮蔽，不需要重写业务 AST。宿主原生 globals 保持隔离，Header 字典复制后适配。作者自身严格模式仍保留。Function 构造代码、任意全局反射与原生引擎差异不伪造支持。

来源 API presence 一致：QX 使用 task/prefs/notify，Loon 使用 httpClient/persistentStore/notification。外端 Loon presence 使用明确的兼容标识，不虚构真实设备、版本号；实际版本、sourcePath 等不可恢复字段列入能力边界。原生来源与目标分支使用同一个 runtime policy。

## API 行为

Header：采用 ScriptHub 的大小写无关、小写键兼容策略，这是明确接受的规范化行为，不声称保留原键大小写或重复大小写键。修正 delete、in、hasOwnProperty、Symbol 及 descriptor；大小写别名的非 configurable 属性受 Proxy 不变量限制，明确报错。

HTTP：方法动态派发到相应原生方法；callback 保留 callback，task 返回 Promise。网络失败拒绝、缺失响应拒绝；不吞掉错误。来源默认值和时间单位按目录映射；QX 未说明选项在调用时省略，原实参表达式仍正常求值。并发请求不使用全局 active 限制。二进制保留准确 byteOffset/byteLength，同时提供 UTF-8 文本视图；具体原生字符集、详细错误对象、Cookie 状态、旧客户端版本仍是边界。

存储：支持动态 String 键值，默认键仅来自明确来源名称。QX 单键删除对应原生 remove 或 callback store null 删除；不把空字符串当删除。读取缺失值与失败返回保留原生行为，不能宣称所有 null/undefined/空值契约已等价。

通知：沿用已建立的字段映射，QX 来源或目标的未说明附加参数按用户要求省略，保留构造副作用。没有目标 API 的延迟/动作在调用时报错，不造空实现。

完成结果：动态对象、参数和包装函数直接调用；状态格式、byte fields、flat/response 包装按宿主转换。未知 QX 参数省略；其它不可映射字段报错。QX echo 类型必须有正确触发声明，body/header 约束在调用时检查。不根据正文猜测输出和修改声明。

## 发布和报告

每 URL 一个源名共用 JS，业务正文一次，原始字节单独精确保留。runtimePolicyVersion=2、validationMode=api-runtime-compatibility 明确区分 API 组合成功与整脚本/实机认证。声明身份、phase/binary 必须明确；多个名称无法绑定时不猜默认存储键。source-bound API sidecar 保留 URL/原件/计划摘要和描述性位置，但不再记录伪静态证明。Actions 同事务更新正文、脚本、清单及引用；本地不生成生产产物。

## 验证与维护

API 标准向量与模拟原生传输覆盖：Header get/set/delete/has、七方法/并发/失败、动态存储、完成值、参数、通知与二进制。以合成 API 程序检查包装与备份事务；不加载仓库脚本作为代码放行样本。新客户端差异进入共同目录或运行时模块，先修正可复用上游方案，不再增加脚本名白名单、逐实参证明器或重复兼容层。
